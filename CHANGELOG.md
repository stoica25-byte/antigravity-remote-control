# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-23
### Added
- Initial public release of Antigravity Remote Control Center.
- FastAPI backend with Uvicorn.
- Vanilla JS Single Page Application (SPA).
- IDE Remote Access with gRPC-Web streaming proxy.
- Second Brain Integration for Obsidian Quick Capture.
- Agent Session Browser for Antigravity agents.
- Cyber-Noir HUD UI.
- JWT Authentication with rate limiting.
- Windows automation scripts for easy startup.
- Tunnel management (Cloudflare / Ngrok) integration.
