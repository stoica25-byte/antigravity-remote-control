# Contributing to Antigravity Remote Control Center

Thank you for your interest in contributing! This document provides guidelines for contributing to the project.

## How to contribute
1. Fork the repository.
2. Create a new branch for your feature or bugfix (`git checkout -b feature/your-feature`).
3. Commit your changes (`git commit -am 'Add some feature'`).
4. Push to the branch (`git push origin feature/your-feature`).
5. Open a Pull Request.

## Reporting bugs
Use the provided issue template to report bugs. Include clear steps to reproduce, expected behavior, actual behavior, and environment details.

## Suggesting features
We welcome new ideas! Open a feature request issue using the template to discuss proposed changes before implementation.

## Pull requests
Ensure your PR has a descriptive title and follows the PR template. Keep PRs focused on a single change.

## Code standards
- **Python:** Follow PEP 8 guidelines. Use type hints where possible.
- **JavaScript/Frontend:** Use consistent naming conventions (camelCase for variables, PascalCase for classes) and structure.
