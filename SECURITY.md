# Security Policy

## Reporting vulnerabilities
If you discover a security vulnerability within this project, please DO NOT create a public issue. Instead, send an email directly to the repository owner or open a draft security advisory if applicable on GitHub. We will address it as soon as possible.

## Disclaimer
This project is an educational and portfolio project. While we strive to implement robust security features (like JWT auth and rate limiting), it is provided "as is" without warranties. Use at your own risk.

## Safe usage recommendations
- **VPN:** Use a VPN when accessing your tunnels from public networks.
- **Tunnel URLs:** Do NOT share your Cloudflare or Ngrok tunnel URLs with anyone.
- **Rotate Credentials:** Regularly rotate your JWT secrets and tunnel authentication tokens.
- **Local Use:** This is designed for local hosting and personal access only. Do not expose it as a public service.

# Política de Seguridad

## Informar sobre vulnerabilidades
Si descubres una vulnerabilidad de seguridad en este proyecto, por favor NO crees una incidencia pública. En su lugar, envía un correo electrónico directamente al propietario del repositorio o abre un aviso de seguridad en borrador si es posible en GitHub. Lo abordaremos lo antes posible.

## Descargo de responsabilidad
Este proyecto es de carácter educativo y de portafolio. Aunque nos esforzamos por implementar funciones de seguridad robustas (como autenticación JWT y limitación de tasa), se proporciona "tal cual" sin garantías. Úsalo bajo tu propia responsabilidad.

## Recomendaciones de uso seguro
- **VPN:** Usa una VPN al acceder a tus túneles desde redes públicas.
- **URLs de Túneles:** NO compartas tus URLs de túneles de Cloudflare o Ngrok con nadie.
- **Rotar Credenciales:** Rota regularmente tus secretos JWT y tokens de autenticación de túneles.
- **Uso Local:** Esto está diseñado solo para alojamiento local y acceso personal. No lo expongas como un servicio público.
